Sistema para Apoio à Aprendizagem de Python

Uma plataforma web desenvolvida para auxiliar estudantes de engenharia na fixação de conceitos de programação e na resolução de problemas práticos.

Este sistema integra o ecossistema do Projeto Monitoria de Programação pra engenharia, oferecendo um repositório interativo de questões, materiais complementares, códigos de suporte e gabaritos oficiais para as disciplinas de computação.

Acessar Banco de Questões Acesso Restrito (Admin)

📚 Questões Práticas

Acesso a um banco diversificado de questões voltadas para a engenharia, organizadas por nível de dificuldade, matéria (CE I e CE II) e tipo.

💻 Códigos e Datasets

Possibilidade de baixar arquivos complementares e analisar códigos de suporte estruturados para acelerar a aprendizagem em Python.

⚙️ Gestão Centralizada

Painel administrativo protegido por senha para cadastro, edição e exclusão simplificada de conteúdos pedagógicos.
